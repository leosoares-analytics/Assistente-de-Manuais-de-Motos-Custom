## 🎯 Problema de Negócio

  Poucos proprietários de veículos de fato leem o manual do proprietário do jeito correto e em momentos precisam de informações especificas desse manual desde para calibrar o pneu a forma correta até lubrificação de uma corrente.

## 🚀 Solução Desenvolvida

  Com base nessa dor encontrada foi desenvolvido esse assistente de manuais (baseado em IA).
  Esse assistente é especializado em motos custom do mercado brasileiro de baixa a média cilindrada (100cc - 650cc)

## 📚 Glossário

| Termo      | Definição                                                          |
| --------   | ------------------------------------------------------------------ |
| RAG        | Busca dados externos para enriquecer as respostas da IA.           |
| Chuncking  | Divisão de textos grandes em pedaços menores e processáveis.       |
| Embedding  | Conversão de texto em vetores numéricos com significado semântico. |
| Vector Base| Banco de dados otimizado para armazenar e buscar vetores.          |
